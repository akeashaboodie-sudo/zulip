## Overview  

This repository is a **fork of [Zulip](https://zulip.com)**, an open-source team collaboration tool that merges the best aspects of email and chat through **topic-based threading**. This design enables efficient communication for both live and asynchronous team discussions.  

The project was forked and explored as part of a **PhD Computer Applications assignment** to gain practical experience with GitHub, open-source collaboration, and Linux shell operations.  

Zulip is used globally by Fortune 500 companies, open-source projects, and research organizations. With contributions from over **1,500 developers** and **500+ commits monthly**, it remains one of the most active open-source chat platforms.
